# پورتفولیو

سایت ساده و بدون سرور. همه‌ی محتوا (کارها، دسته‌ها، متن‌ها، ایمیل و اینستاگرام) در `content.js` است.

- اضافه کردن کار جدید: یک بلوک در `projects` کپی کن و تغییر بده.
- ویدئو: روی یوتیوب آپلود کن (Unlisted هم کافی است) و فقط ID را در `youtube` بنویس.
- کاور: در `assets/covers/` بگذار (بهتر است ۴:۵، مثلاً ۱۲۰۰×۱۵۰۰). اگر خالی باشد، کاور یوتیوب استفاده می‌شود.
- عکس خودت: `assets/img/` و مسیرش در `about.photo`.
- لینک مستقیم فارسی: `?lang=fa` آخر آدرس سایت.

اجرای محلی: `python3 -m http.server -d portfolio` و باز کردن `localhost:8000`.
